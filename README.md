# Ana Flavia Johnson — Psicóloga

Site estático responsivo, em português, com agendamento pelo WhatsApp e links para o Instagram.

## Executar localmente

Na pasta do projeto: `python -m http.server 8095`. Abra http://localhost:8095.

Não há instalação de dependências ou etapa de build. GitHub Pages serve os arquivos da raiz da branch `main`.
